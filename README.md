# Godot AmbiBin Player v0.1.0

Copy **addons/ambisonic_player** into a project using **Godot 4.8 beta 3**. The package includes Windows x64 and macOS Apple Silicon and Intel. See the [add-on instructions](addons/ambisonic_player/README.md) for playback, WAV import, and SOFA setup.

A synthetic first-order test recording is at [front-noise-burst.wav](addons/ambisonic_player/examples/front-noise-burst.wav).

[Corresponding source and build instructions](https://github.com/hectorC/Godot_AmbiBin_Player/tree/90e56a880b882f0d79c9c9dca29a829e1117197f) · [License](LICENSE) · [Third-party notices](addons/ambisonic_player/LICENSES.md)

The [Windows native build](https://github.com/hectorC/Godot_AmbiBin_Player/tree/c8871e3a31d5af93023b9cee24c2f6850a512853) uses OpenBLAS. The [macOS universal build](https://github.com/hectorC/Godot_AmbiBin_Player/actions/runs/43771770489) was built from commit [7b9409e](https://github.com/hectorC/Godot_AmbiBin_Player/tree/7b9409ee6f98ed47de278df6ca4f05824e291b39).
